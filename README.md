# EasyNPCHousing
This simple mod lets you create simple NPC houses with the click of a button. 

# New Item
The NPC Housing Wand is a consumable item that lets you automatically build an NPC house.

<img width="542" height="227" alt="image" src="https://github.com/user-attachments/assets/0a92ba85-ff5f-4297-8d65-1261c24537a8" />

# Crafting
The item can be crafted at a workbench and costs 50 wood.

<img width="374" height="106" alt="image" src="https://github.com/user-attachments/assets/604dac6b-1054-48e4-90fc-5a0d416a85f4" />

# Using the item
Simply hover over the item in your inventory and click somewhere to place the house! Your mouse's position will be the bottom left of the house.

<img width="324" height="280" alt="using-item" src="https://github.com/user-attachments/assets/e5a96062-2318-4b78-ad29-aa97632620cb" />

# About the config setting
There is a config setting that lets you decide if you want to be able to overwrite tiles or not. It is off by default, meaning you cannot overwrite tiles, and it currently only works on tiles, not walls or other items.
